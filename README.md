## 🚀 Experiencia destacada

- **Micro-frontends con Nx en el sector asegurador:** feature libs por ecosistema (Hogar, Movilidad, Salud), librerías de acceso a datos y utilidades comunes (guards, interceptors, pipes) dentro de un monorepo, con calidad y seguridad integradas en el pipeline (Jenkins, SonarQube, Grafana, OAuth2).
- **Producto de IA para planificación docente:** aplicación web con Spring Boot y la API de OpenAI que automatiza la planificación de clases según asignatura, nivel y perfil del alumnado; se escaló de Ecuador a México con distintos marcos educativos.
- **Asistente RAG:** búsqueda semántica sobre libros en PDF con LangChain y una base de datos vectorial.
- **Aplicación de gestión porcina:** diseño de la base de datos y de los módulos, y desarrollo del frontend en Angular; la primera versión funcionó en producción en granjas de México.
- **Modernización de un ERP Java:** migración a una versión moderna de Java y división del producto en versiones comercializables por separado.
